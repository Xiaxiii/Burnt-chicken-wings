# 焦香鸡翅（预设裁缝铺）· Burnt chicken wings 🍗

SillyTavern（酒馆）聊天补全预设工具：整理分组、跨预设缝合、思维链检查、方案与 API、加载体检。

缝合时先分析两个预设让条目生效的方式，再自动调整写法，使缝入的条目在目标预设中正常生效。可识别的写法包括：

- 变量写法：正文写入变量（setvar / addvar）、各条目登记问句变量、向汇总变量追加内容
- 思维链读取条目的方式：读取变量，或在文字中提及条目名称
- 初始化条目、外层标签（如 `<text_style>`）、深度插入、`{{if}}` 条件、EJS 脚本、正则

缝合预览逐条列出：条目在原预设中的作用、缝入后的调整、思维链能否读取。需要时可一键接入思维链。

## 安装

### 扩展版（推荐）

酒馆 → 扩展（三个方块图标）→ **安装扩展** → 填入：

```
https://github.com/Xiaxiii/Burnt-chicken-wings
```

更新：在扩展管理中点「更新」，或在扩展页「预设裁缝铺」设置框中点「检查更新」。设置框标题旁显示当前版本号。

### 脚本版（酒馆助手）

待功能稳定后发布。两个版本同时安装时，只有扩展版会启动。

## 打开方式

- 魔棒菜单 →「焦香鸡翅」（名称可在扩展页设置框中点「修改」更改）
- 扩展页「焦香鸡翅」设置框 →「打开」
- 在输入框发送 `/atelier`

修改即时自动保存，有修改时可「撤销」或「确认」。每批修改开始前自动备份一次，每个预设保留最近 10 份，可在顶栏的时钟按钮中查看、恢复或下载。

## 基本操作

- **选位置**（缝合的目标、整理页的移动）：点组名，放在该组之后；展开分组后点组内条目，放入组内。
- **新建分组**：点「＋ 新建分组」，填写名称，再点一个位置。新分组为空，之后可移入或缝入条目。
- **拖动**：条目右侧的把手拖动单条，分组右侧的把手拖动整组。
- **方案与 API**：方案记录条目开关，可同时记录人设和 API 站点；套用时一并切换。

## 加载体检

酒馆打开较慢时，可在「更多 → 加载体检」中查看：全部预设的总大小（酒馆每次打开都会完整下载）、各扩展在设置文件中的数据量、角色卡数量和当前聊天长度、打开时最慢的请求，并给出处理建议。检查只在本浏览器中进行，不上传任何数据。

## 外观

在「更多 → 外观」中选择配色：默认跟随酒馆主题（自动改为不透明，保证文字清楚），也可选用「花田」「晴野」油画渐变，或杏色、鹅黄、芽绿、夜雾。还可设置自定义背景图，图片只保存在本浏览器。

## 开发

源码在 `src/`，修改后运行：

```
node build.mjs          # 生成 index.js（扩展版）；dist/ 中的脚本版暂不提交
node test/run-core.cjs  # 核心逻辑测试
```

仓库中不包含任何真实预设。测试用的「众生相风格」预设为代码生成的测试数据（`test/fixtures/make-zsx-like.cjs`）。使用真实预设测试时，放入 `test/site/local/`（已加入 .gitignore）。

`index.js` 为生成文件，请勿直接修改。
