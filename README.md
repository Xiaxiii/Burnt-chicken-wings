# 焦香鸡翅（焦香鸡翅）· Burnt chicken wings 🍗

SillyTavern（酒馆）聊天补全预设工具：整理分组、跨预设缝合、思维链检查、方案、加载体检、预设清理。

缝合时先分析两个预设让条目生效的方式，再自动调整写法，使缝入的条目在目标预设中正常生效。可识别的写法包括：

- 变量写法：正文写入变量（setvar / addvar）、各条目登记问句变量、向汇总变量追加内容
- 思维链读取条目的方式：读取变量，或在文字中提及条目名称
- 初始化条目、外层标签（如 `<text_style>`）、深度插入、`{{if}}` 条件、EJS 脚本、正则

缝合预览逐条列出：条目在原预设中的作用、缝入后的调整、思维链能否读取。需要时可一键接入思维链。

## 安装

### 扩展版（推荐）

酒馆 → 扩展（三个方块图标）→ **安装扩展** → 填入：

```
https://github.com/Xiaxiii/Burnt-chicken-wings
```

更新：在扩展管理中点「更新」，或在扩展页「焦香鸡翅」设置框中点「检查更新」。设置框标题旁显示当前版本号。

### 脚本版（酒馆助手）

待功能稳定后发布。两个版本同时安装时，只有扩展版会启动。

## 打开方式

- 魔棒菜单 →「焦香鸡翅」（名称可在扩展页设置框中点「修改」更改）
- 扩展页「焦香鸡翅」设置框 →「打开」
- 在输入框发送 `/atelier` 或 `/焦香鸡翅`

修改即时自动保存，有修改时可「撤销」，或点「完成」结束这一批修改。保存前会核对预设有没有在别处被改过，改过就先问你。每批修改开始前自动备份一次，每个预设保留最近 10 份，可在顶栏的时钟按钮中查看、恢复或下载。备份只存在当前浏览器里，换设备或清除浏览器数据后就没有了。

## 基本操作

- **选位置**（缝合的目标、整理页的移动）：点组名，放在该组之后；展开分组后点组内条目，放入组内。
- **新建分组**：点「＋ 新建分组」，填写名称，再点一个位置。新分组为空，之后可移入或缝入条目。
- **新建、复制、编辑条目**：「工具 → ＋ 新建条目」放在选中的条目之后；多选后「更多 → 复制」；点条目右侧的眼睛可改名称、正文、角色和插入位置，点「保存」才生效。
- **分组开关**：只切换分组标记，保留内部每个条目的独立选择，全关的条目也不会被一起打开。生成时是否按分组过滤取决于宿主支持（如柏宝箱）；不支持时仍按条目开关发送。
- **拖动**：条目右侧的把手拖动单条，分组右侧的把手拖动整组。
- **缝进世界书**：「目标」切换到「世界书」，预设条目、世界书条目都能缝进世界书；预览中可设触发方式、关键词、插入位置、深度和顺序。缝合前自动备份世界书，缝完可在底栏撤销。
- **已选的条目**：缝合底栏点「已选 N 条」查看全部已选条目（跨预设、世界书、粘贴），可逐条去掉。
- **搬到新版**：预设出了新版本时，来源选旧版、目标选新版，在来源旁的「⋯」里点「搬到新版」，旧版中缝进去的条目会按原位置搬到新版，开关状态沿用旧版，原先接入思维链的重新接入。
- **方案**：方案记录条目开关，可同时记录人设和 API 站点；套用时一并切换。

## 加载体检

酒馆打开较慢时，可在「更多 → 加载体检」中查看这一次打开的测量结果：

- **时间点分开记**：页面 DOM 就绪、酒馆启动完成（APP_READY）、启动完成后仍在进行的请求。「聊天可操作」目前无法可靠测量，显示「未测得」，不用启动完成的时间代替。
- **请求按类别统计**：设置及预设、全部角色列表、单张角色详情、聊天记录、扩展清单、扩展脚本与样式、世界书、头像与背景、设置保存，以及已识别的第三方快速接口（柏宝库、鸡尾酒+）。同类请求同时进行时，耗时按时间段的并集算，不相加。
- **体积分三种**：实际传输（经过网络的字节，缓存命中时为 0）、压缩后、解压后。跨域拿不到的标「未取得」。全部预设的大小是内存中序列化后的统计量，不是网络传输量。
- **每笔请求明细**：开始、耗时、等待首字节、接收阶段。等待首字节包含网络往返，不等于服务器处理时间。
- **导出诊断报告**（JSON）：包含版本、统计口径和这次测量覆盖不到的部分；不含预设正文、聊天内容和密钥，角色、头像、聊天等文件名已隐去。

体检只读取浏览器已有的请求记录，不重新下载预设、角色或扩展源码，不判断请求是哪个扩展发起的。检查和导出都只在本浏览器中进行，不上传任何数据。

## 加载与兼容

扩展页「焦香鸡翅」设置框里的「加载与兼容」一栏，显示和启动加速有关的扩展现在的状态：柏宝箱、柏宝库（后端）、鸡尾酒、鸡尾酒+、酒馆助手。

- 平时只看页面上已有的信息，不发请求；点「检查兼容性」才读取扩展列表、探测后端。
- 「安装」「开启」「后端可用」「运行中」「版本」分开显示。版本标「已识别但未验证」（核对过这个版本的源码，但没有在真实酒馆里一起测试过）或「未知」。
- 设置／预设读取、角色列表、扩展清单与预加载，同一请求只应由一个功能接管；两个都开着时会提示重叠。
- 本扩展只做检测和体检，不接管任何请求，也不改其他扩展的开关。

## 预设清理

酒馆每次打开都会把预设文件夹里的全部预设下载一遍。在「更多 → 清理」中可以看到每个预设的大小，以及自动标出的可清理预设：与另一个完全相同、有新版本、同系列副本、大部分条目与另一个相同。正在使用的预设不能勾选。

- **归档**：把预设移到酒馆服务器的用户文件目录，打开酒馆时不再下载，在「已归档」中可随时恢复，换设备、换浏览器都能恢复。套用方案时，如果对应预设已归档，会自动恢复。
- **下载**：把勾选的预设打包成 zip 下载到本地。
- **删除**：从服务器上删除，无法在酒馆中恢复，删除前可先下载。

「清理」还有四栏：

- **扩展数据**：设置文件中各扩展的数据量；可「实际检测」哪些数据已没有扩展使用（卸载后的残留），删除前先下载备份。
- **角色卡**：同名角色卡，删除时保留聊天记录。
- **世界书**：内容完全相同的、没有条目的世界书，删除前先下载 zip。
- **本地备份**：本扩展在本浏览器中保存的预设备份。

云端酒馆和安卓本地酒馆（Termux）均可使用。本地酒馆没有带宽瓶颈，归档对打开速度的提升较小。

## 外观

在「更多 → 外观」中选择配色：默认跟随酒馆主题（自动改为不透明，保证文字清楚），也可选用「花田」「晴野」油画渐变，秋樱、海雾、春芽、春和、玫瑰芋泥、日落海岸等画面风格背景，或深色「夜雾」。「文字大小」可选小、标准、大，每台设备单独记；手机上默认比平板、电脑紧凑。还可设置自定义背景图，图片只保存在本浏览器。

## 开发

源码在 `src/`，修改后运行：

```
node build.mjs              # 生成 index.js（扩展版）；dist/ 中的脚本版不提交
node test/run-core.cjs      # 核心逻辑测试
bash test/run-browser.sh    # 全部浏览器检查（首次会在 test/ 下装 playwright 和 jquery）
```

推送和提交合并请求时，GitHub Actions 会自动构建并跑以上测试（`.github/workflows/test.yml`）；`index.js` 与源码不一致时会报错，记得构建后一起提交。

仓库中不包含任何真实预设。测试用的预设都是代码生成的测试数据（`test/fixtures/make-zsx-like.cjs` 和 `test/run-core.cjs` 里的合成预设）。核心测试里有 6 项需要本地的 Ako 预设，没有时自动跳过，同样的场景已有合成预设覆盖。使用真实预设测试时，放入 `test/site/local/`（已加入 .gitignore）。

`index.js` 为生成文件，请勿直接修改。
