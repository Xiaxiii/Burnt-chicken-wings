# 预设裁缝铺 · Burnt chicken wings 🍗

SillyTavern（酒馆）聊天补全预设的小工具：**整理分组、跨预设缝合、思维链检查、开关方案、API 站点**。

缝合的时候会先看懂两边预设"是怎么让条目生效的"，再自动改写，让缝进来的条目在新预设里真的能用上：

- 变量包裹（setvar / addvar 整段包进变量）、各自登记问句变量、往汇总变量里追加片段
- 思维链靠变量读条目，还是靠文字点名
- 初始化条目、外层标签（比如 `<text_style>`）、深度注入、`{{if}}` 条件、EJS 脚本、正则

缝合预览里会用大白话写清楚：**它在原预设里怎么起作用 → 缝过去改了什么 → 思维链会不会想到它**。需要的话一键「挂进思维链」。

## 安装

### 扩展版（推荐）

酒馆 → 扩展（三个方块的图标）→ **安装扩展** → 填入：

```
https://github.com/Xiaxiii/Burnt-chicken-wings
```

以后在扩展管理里点「更新」，或者在扩展页「预设裁缝铺」设置框里点「检查更新」，就能拿到新版本。设置框标题旁边会显示当前版本号。

### 脚本版（酒馆助手）

功能稳定后再出。到时两个版本同时装也没关系，只有扩展版会启动。

## 打开方式

- 魔棒菜单 →「预设裁缝铺」
- 扩展页的「预设裁缝铺」设置框 →「打开裁缝铺」
- 或者在输入框发 `/atelier`

保存前会自动备份预设（最近 15 份），所有改动都可以撤销。

## 加载体检

酒馆打开很慢时：更多 →「加载体检」（或设置框里的「加载体检」）。会量出全部预设一共多大（酒馆每次打开都会把所有预设整个下载一遍）、哪些扩展在设置文件里存了很多数据、角色卡和当前聊天有多长、打开时哪些请求最慢，并给出能做的事。只在你自己的浏览器里看，不会上传任何东西。

## 外观

右上角调色板按钮可以换颜色：默认跟随酒馆美化（自动补成不透明，免得背景透出来看不清字），也可以选雾霾蓝、豆沙粉、抹茶绿、燕麦奶茶、薰衣草、海盐、夜雾。

## 开发

源码在 `src/`，改完运行：

```
node build.mjs          # 生成 index.js（扩展版）；dist/ 里的脚本版暂不提交
node test/run-core.cjs  # 核心逻辑测试
```

仓库里不放任何预设文件。测试用的"众生相风格"小预设是代码生成的纯测试数据（`test/fixtures/make-zsx-like.cjs`）；想用真实预设测试，放进 `test/site/local/`（已在 .gitignore 里）。

不要直接改 `index.js`，它是生成出来的。
