预设裁缝铺 1.4.0

整理分组、跨预设缝合、思维链检查、方案与 API、加载体检。
打开方式：魔棒菜单 →「预设裁缝铺」，或在输入框发送 /atelier。
修改即时自动保存，每批修改开始前自动备份。扩展版和脚本版同时安装时，只有扩展版启动。

1.4.0
- 保存：修改即时自动保存。有修改时顶栏显示「撤销」「确认」，「确认」表示这一批修改完成。顶栏右侧的时钟按钮可查看备份：每批修改开始前自动备份一次修改前的版本，每个预设保留最近 10 份，可恢复或下载。整理页的「备份」按钮移到顶栏，各页面通用。
- 「开关方案」和「API 站点」合并为「方案与 API」。保存方案时可同时记录 API 站点，套用方案时一并切换预设、开关、人设和 API。站点标题显示使用它的预设。
- 使用中的站点跟随酒馆里的实际模型，不再显示旧模型。
- 模型选择改为扩展自己的选择框：可搜索，可直接输入名称，高度不超出屏幕。
- 整理页：选中条目后底栏有「取消」按钮；移动时的按钮改为「取消」；移动完成后自动取消选中。
- 配色：除「花田」「晴野」外，改为杏色、鹅黄、芽绿三套，保留「跟随酒馆主题」和「夜雾」。
- 思维链页「说明」增加「接入思维链」和「手动指定思维链」的解释。

1.3.9
- 新建空白分组：在整理页或缝合页点「＋ 新建分组」，填写名称，再点一个位置。之后可移入或缝入条目。分组中的条目全部移走后，分组保留在原处，可在分组菜单中删除。
- 整理页：分组右侧增加拖动把手，可拖动整组；分组菜单增加「移动整组」。「全部折叠」「全部展开」合并为一个按钮。
- API 站点：修复已连接时「获取模型列表」取不到模型的问题。现在直接向酒馆请求模型列表，获取后在下拉框中选择，也可手动输入。切换站点时等待连接完成再提示结果。
- 去掉重复功能：顶栏换色按钮（在「更多 → 外观」中设置）；缝合页「整理分组」模式（由「＋ 新建分组」和整理页代替）；缝合底栏「两边写法」（并入缝合预览）；思维链页重复的统计文字。
- 保存状态只显示「已保存 / 保存中 / 待保存」，保存失败时才显示重试按钮。编辑条目只保留一个「完成」按钮。
- 新配色「花田」「晴野」（油画渐变），替换豆沙粉和雾霾蓝。外观中可设置自定义背景图，图片只保存在本浏览器，自动裁去截图的纯色边，遮罩浓度可调。
- 全部界面文字和分析说明改为书面语。
