预设裁缝铺 1.3.8

整理分组（点选建组、只拖把手）、跨预设缝合（自动改变量写法、自动挂进思维链）、思维链检查、开关方案、API 站点。
打开方式：魔棒菜单 →「预设裁缝铺」，或在输入框发 /atelier
保存前会自动备份预设。扩展版和脚本版同时装时，只有扩展版会启动。

1.3.8
- 选位置改了：点组名＝放在这组后面（组外）；展开组再点组内条目＝放进组里。缝合「缝到哪儿」和整理页「移动」都是这样。去掉「缝进这组 / 放进这组」；列表顶上有「↑ 最前面」，展开的组里有「↑ 组内最前」。
- 来源里整组选中、缝到组外时，默认在目标里照原名建组（缝合预览里可改成「放进新分组」或「不分组」）。原来的「＋ 缝成一个新分组」并到这里。
- 整理页：整组选中后移到组外，分组跟着走，不再散开。拖到组头：上半＝组前面，下半＝组内最前（展开时）或组后面（折叠时）。
- 手机上：整理页工具栏不再「工具」和四个按钮同时出现；移动条压成一行；缝合底栏的位置写全，按钮不折行。
- 删掉一批多余的说明和提示语。

1.3.7
- 整理：点整行即选中，看内容点眼睛。选中后底栏只剩「移动 / 建分组 / 开 / 关 / 更多」。
- 移动：点「移动」后，点条目＝放到它后面，「放进这组」＝组末尾，组内有「↑ 放在组开头」；顶部 ↑ ↓ 微调一格。
- 分组菜单去掉与圆圈重复的「全选本组」。
- 缝合位置标记更醒目：选中的条目高亮，下方出现「⬇ 缝在这里」；分组折叠时，组标题显示「缝在这组」。修正底栏显示「undefined」。
- 思维链页：去掉每行的「设为思维链」，改为一个「手动指定思维链」入口。
- API 站点：点站点展开详情，可直接选模型；「现在连着」里也能直接换模型。

1.3.6
- 缝合「缝到哪儿」：顶部新增「＋ 缝成一个新分组」，取名后点位置即可；点在组内时，新分组放在该组之后。
- 分组左侧改为展开箭头；展开后点条目＝缝在它后面，组内第一行「↑ 缝在组开头」。
- 思维链页说明文字精简。
- 修正：预设较大时，浏览器本地草稿备份空间不足被误报为「保存失败」。现在会先清理其他预设的旧草稿；真的保存失败时显示具体原因。

1.3.5
- 修正：装了百宝箱时，在「当前预设」里建分组（缝合页的整理分组、整理页都一样），保存后会被百宝箱用它内存里的旧分组盖回去，看起来像没建成、只改了个名。现在每次保存都会让百宝箱重新读一遍分组。
- 建新分组时，如果选中的正好是某个组的全部条目，会先问你是「给这个组改名」还是「还是建新分组」。
- 建好的新分组会自动展开并滚到眼前；保存后要是又被别的插件改没了，会提醒你。

1.3.4
- 扩展页里的设置框重做：标题旁边显示版本号，按钮横排（不再竖着挤成一列），可以直接「检查更新 / 现在更新」，展开就能看更新说明。没有悬浮球。
- 新增「加载体检」（更多 → 加载体检，或设置框里的按钮）：量一下酒馆打开时慢在哪——全部预设一共多大（酒馆每次打开都会整个下载一遍）、哪些扩展存了很多数据、角色卡和聊天多长、哪些请求最慢，并给出能做的事。只在你的浏览器里看，不上传任何东西。

1.3.3（用【小冰块】v3.83 测）
- 修正：宏里少写一个 }（比如 {{user}：…）时，后面的 {{getvar}} 会被漏掉，导致误报"没人读这个变量"。
- 小冰块的写法：文风正文包在 <writing_style：名字> 里、只登记名字 {{addvar::文风::名字}}；缝进来会照样包标签、照样登记名字，不会把别的预设的问句当成名字登记进去。
- 包进变量的单选（顶栏规范这类 setvar）也有"别顶掉你选好的那项"的保护；真的加入单选时，改动里会写明。
- 读这个变量的条目（小剧场一键开关之类）全关着时会提醒：要打开它，缝进来的才会发出去。由一键开关统一发出去的条目，挂进思维链默认不勾。
- 共用标签 <small_theater: 名字> 时，用后面的名字称呼这条。
- 写法分析：按"由谁统一发出去"合并成一行，并标出关着的一键开关；分得清"整段包进变量"和"只登记名字"。

1.3.2
- 缝合预览改成两张卡片：「直接缝入」（不改写法，原样放进去）/「按目标写法缝入」（照目标预设的写法改好），各带内容预览和改动要点；选哪种，下面的完整正文跟着变。去掉了原来那个四选一的"写法"下拉。
- 碰到单选槽位时多一张卡片「按目标写法缝入，并加入单选 X」，由你决定要不要顶掉同类。
- 新勾选：条目名后面加上「（来自 来源预设）」。
- 「缝到哪儿」加了「整理分组」：点选条目建新分组、移出分组；分组右边 ⋯ 可以改名、解除分组。
- 思维链有好几个「选一」版本、都读同一组变量时（V2.61），挂进思维链会加到每个版本里，换版本也不会丢；编号变量接着编号（修复模式18）。
- 登记的内容照邻居的格式写（[模式：名字]、文风选择 追加名字等）；方括号标题支持中文。

1.3.1
- 认得没有分组、名字也不带"思维链"的思维链：从「思维链始 / 思考开始 / 单独一行的 <thinking>」到「思维链终 / 思考结束 / </thinking>」之间都算（Ariadne）。
- 认得注释分区 <!-- START: WRITING_STYLE --> … <!-- END: … -->（众生相），以及思维链里用 writing_style 这类名字点名整个分区。
- 单选槽位：好几条都往同一个变量登记问句、只开一条的写法（Ariadne 的 叙事风格1/2/3、故事基调）。同类条目缝进来会照样登记、套上 [Writing Style: 名字] 这类标题；不是同一类的不会加入，免得顶掉你选好的那一项。
- 思维链靠文字点名、又没提到某个分区时（众生相的 STORY_TONE），可以在思维链里加一步点名整个分区，按原来的 Phase 编号接着写。
- 标题格式互换：# writing_style: 名字 ↔ [Writing Style: 名字]，不会叠两个标题。
- 修正：英文普通单词碰巧出现在思维链里（narrative 之类）不再算"提到"；句子里提到 <thinking> 不再被当成思维链开头。
- 写法分析会把关着的选项也算进去，能看出单选槽位。

1.3.0
- 缝合前先分析两边预设"是怎么让条目生效的"：变量包裹、问句变量、汇总变量、靠文字点名的思维链、初始化条目、外层标签、深度注入、条件宏/脚本、正则。缝合预览里写清楚"它在原预设里怎么起作用 → 缝过去改了什么"。
- 挂进思维链支持三种写法：各自的问句变量 / 往汇总变量里追加 / 思维链靠文字点名时在思维链里加一行点名；来源里被思维链用到的条目默认挂上。
- 修正：邻居各用各的标签时，不再把邻居的标签套给新条目。
- 外观：默认跟随酒馆美化并自动补成不透明；新增 7 套莫兰迪色卡（雾霾蓝、豆沙粉、抹茶绿、燕麦奶茶、薰衣草、海盐、夜雾）。顶部调色板按钮可随时换。
- 缝合页上下分区可以拖动调整大小；选择框和搜索框改小。
- 思维链页改成大白话：一句话结论、"思维链是什么"说明、状态改名为 读到了 / 文字提到 / 没提到。
- 方案、API、外观合并到「更多」页。
- 新增扩展版（可在酒馆里一键安装和更新）。

1.2.0
- 缝合时自动「挂进思维链」；写法转换（纯文本 / 包进变量 / addvar↔setvar）改成大白话说明。
- 修正：邻居各用各的变量时，不再误当成共用变量去覆盖邻居的问句。
- 思维链页「没提到」的条目可一键挂进思维链。

1.1.3
- 分组只按原格式写回一种（百宝箱分组里不会再套一层同名分组，并清掉旧版镜像）；能读成员列表式分组。
- 在酒馆里直接改过预设后，不再用旧草稿覆盖。
- 思维链检查认得 <text_style> 这类外层标签。

1.1.2 及更早
- 识别缝合带来的冗余变量包裹；思维链页一键修复；即时草稿恢复及自动保存；标签自然排序；整批移动保留点选顺序。
