焦香鸡翅 2.5.16

用于整理、缝合聊天补全预设，并提供思维链检查、方案、加载体检和预设清理。
打开方式：魔棒菜单 →「焦香鸡翅」，或悬浮球（「更多 → 外观 → 入口」里选）；或在输入框发送 /atelier、/焦香鸡翅。名称可在扩展页设置框中修改。
修改即时自动保存。每批修改开始前自动备份（可关闭）。扩展版与脚本版同时安装时，只启动扩展版。

2.5.16
- 油画、毛玻璃配色下，选择预设、选择模型等弹窗里的列表行和搜索框底色调淡，画能透出来。2.5.14 给弹窗加了画，但列表行占满弹窗、白底盖住了画。
- 列表行的底色直接写在行上，别的主题或扩展改按钮、列表项的样式盖不过。

2.5.15
- 编辑站点时点眼睛看已保存的密钥，密钥填进框里，可以选中复制；旁边多一个复制按钮。以前只显示成框里的灰色提示字，选不中。框里的密钥没改就不算新填的，保存时不会再存一遍。
- 用 http 打开的酒馆也能复制（浏览器在 http 下不给剪贴板接口，改用选中后复制）。

2.5.14
- 弹窗（选择预设、选择模型、各种菜单和对话框）也有画：油画、毛玻璃配色用和面板同一幅画，设了背景图就用背景图加遮罩。以前弹窗只有一层纯色，里面的选项、搜索框看着是一片白。

2.5.13
- 站点导入认别的扩展导出的分组格式（grouped-api-configs-export）：网址（customUrl）、名称（groupName）、密钥（apiKeys）、模型（customModel，不带站点前缀，跳过占位）、当前模型（isActive）都能读到；文件里有分类时，按模型的 categoryIds 建成这个站点的分类，同名分类合并。
- 导出的站点文件带上模型分类。
- 导入预览多写模型数、分类数。

2.5.12
- 修好搜索框方角白底、下面多一截灰底（整理页、选择模型、选预设、正则、缝合页）。2.5.1、2.5.3 只防了按「搜索框」类型改的样式，没防按类名（带 search）、按搜索键改的。现在圆角、底色、边框直接写在框上，外面那层的类名不再带 search，并清掉别人加的底色和边距。

2.5.11
- 精简站点的说明、导入导出的提示，以及「跟随系统」下面的一行字。

2.5.10
- 站点可以导出、导入 JSON 文件：「站点」标题右边多了「导入」「导出」，和「＋ 添加站点」并排。
  - 导出时选「含密钥」或「不含密钥」。含密钥的文件里是明文密钥，导入后不用重填；更新前或在别的浏览器里存的密钥，这里看不到全文，不会写进文件，导出后会提示有几个。
  - 导入前先列出要导入的站点，写明是新增还是更新、各有几个密钥，点「导入」才保存。密钥照常存进酒馆密钥库。
  - 已有同名、同网址的站点就更新它，不会多出一份：文件里有密钥就换成文件里的，一样的密钥不重复存；站点丢了密钥时，导入一次就补回来。
  - 也认别处常见的写法：网址写成 url、baseUrl、api_url 等，密钥写成 key、apiKey、api_key 等，或 keys 列表（多个密钥）。

2.5.9
- 「当前连接」里模型名的字小一点（iPhone、iPad 上以前至少 16px）。编辑站点窗口里的模型框不变，仍和网址、密钥框一样大。

2.5.8
- 「更多 → 外观」：「跟随手机系统」不再是一张配色卡，改成「配色」右边的「跟随系统」开关。打开后系统是深色时用夜雾，浅色时用下面选中的配色；手机、平板、电脑都跟着系统的深浅色走，系统切换时面板马上跟着变。以前选了「跟随手机系统」的，现在开关是开的，浅色时的配色不变。
- 修好 iPad、iPhone 上弹出菜单的选项叠在一起（如缝合页「更多操作」、方案的 ✏️ 菜单）：说明文字折成两行时，下一项会压住第二行。
- 整理页工具栏：窗口不到 1100px 宽时（iPad 也算），「新建分组、新建条目、智能分组、全部展开、多选排列」收进 ＋ 和 ⋯，这一行只有「预设 🔍 ＋ ⋯」，预设名不再被截短；打开搜索时，搜索框在下面一行。

2.5.7
- iOS 15.4～16.3 上焦香鸡翅加载不出来的问题：有 4 处正则用了这些系统的 Safari 不认的写法，整个扩展在加载时就报错。改成老系统也认的写法；以后再有人写进这类写法，测试会直接报出来。酒馆本身支持到 iOS 15.4，焦香鸡翅现在也一样。
- iOS 16.2 以前的系统上，设了背景图时顶栏、卡片变透明、搜索高亮看不见：补了不透明的后备颜色。
- 搜索不卡了：整理页、选择模型、正则、缝合页、选择列表的搜索框，打字停一下再筛，连打几个字只筛一次；拼音还没选字时不筛（以前每打一个拼音字母都要把整个列表筛一遍）。在模拟中端手机、1200 条目的预设上，连打 5 个字从 5 次 170～355 毫秒的卡顿降到 1 次 56 毫秒。
- 电脑上用中文输入法时，按回车确认拼音候选字不再被当成「完成」「确定」（缝合页搜索、改名、新建分类、输入框弹窗）。
- 密钥框改回密码框：2.5.3 改成普通文本框后，手机键盘可能记住密钥，读屏软件会把它念出来。圆角、底色现在直接写在框上，别的扩展或主题按「密码框」改的样式盖不过。
- 酒馆密钥库里已经删掉的密钥，本浏览器里的留底跟着删掉。
- 「跟随酒馆主题」配深色的酒馆主题时，和 2.5.6 之前的夜雾一样分不出层次：次要文字、强调色都接近白色，酒馆的橙色、蓝色强调色变成浅色。改法同夜雾，卡片底色在深色时换成很淡的一层；设了背景图时不变。
- 新增一项界面检查：320 小屏、标准手机、手机横屏、iPad、电脑五种尺寸下，各页面和常用弹窗没有内容超出屏幕。
- 写错名的必需标签（2.5.6）判断得更准：
  - 看块里面的子标签：预设或正则里写过 <lxs_status> 里有 <时>、<地>，回复里的 <状态栏> 也有，才算确定。
  - 确定时提醒才点名「写成了 <状态栏>」，自动修正才改名。不确定时只提醒必需标签的名字一字不改，免得把世界书里定义的其他块（如小剧场）错改成 <lxs_status>。手动「修正这条回复」有预览，仍可改。
  - 多出几个预设查不到的块时，只有一个结构对得上就认定是它。
  - 扫预设的结果记 60 秒，连着几轮写错名时不必每轮重扫。

2.5.6
- 修好「越提醒越错」：模型把必需标签写错了名字（如预设要 <lxs_status>，它写成 <状态栏>）时，下一轮提醒以前会照前几条回复，点名让 <状态栏> 照常输出，模型就一直写 <状态栏>。现在：
  - 必需标签整个没出现、回复里却多了预设和角色卡都没用到的块，就当作写错了名字。检查结果写明「<状态栏> 预设没有用到，多半是写错了名字的 <lxs_status>」。
  - 提醒写明「上一轮把 <lxs_status> 写成了 <状态栏>：请用 <lxs_status>…</lxs_status>，不要输出 <状态栏>」，不再点名让写错的块照常输出。
  - 只多一个这样的块时，「修正这条回复」和自动修正把它改名为 <lxs_status>，内容不动，状态栏美化就能正常显示。多出几个时只在提醒里点名，不猜。
  - 「用到的标签」从预设开着的条目、预设正则、角色卡文字和正则、全局正则里收集。

2.5.5
- 思维链页标题右边的 ⓘ 放大一些，和「N 项变量读取待核对」这一行居中，右边缘和下面卡片里的原因胶囊对齐，不再往右凸出。

2.5.4
- 入口可以自选：「更多 → 外观」最上面的「入口」，或扩展页设置框里的「入口」，选「魔棒菜单」「悬浮球」或「两个都要」。选「悬浮球」时魔棒菜单里不再显示焦香鸡翅。默认只用魔棒菜单；以前开了悬浮球的，现在是「两个都要」，和原来一样。扩展页的「打开」按钮和 /atelier 一直能用。
- 「显示悬浮球」开关由「入口」代替。

2.5.3
- 修好搜索框、密钥框是方角、下面漏出一截底色的问题（2.5.1 没修好）。原因是别的扩展或酒馆主题按「搜索框」「密码框」这两种类型改了样式，盖过了焦香鸡翅的。这两种框改成普通文本框，不再受影响：键盘照样显示搜索键，密钥照样显示成圆点（浏览器不支持时退回密码框）。

2.5.2
- 「正文格式检查」里标签填错时，报错写在那个输入框下面，框标红，并滚到那里；以前写在窗口最底下。报错里写出是哪个值不对。改动时报错消失，离开输入框时重新检查。
- 标签名先清理再检查：全角字母和符号转成半角，去掉复制时带进来的看不见的字符和误填的尖括号，中文输入法打出的「——」当作下划线。必需标签也可以用分号分隔。

2.5.1
- 看已保存的密钥：保存密钥时在本浏览器另留一份，点眼睛就能看全文，不用改酒馆的 config.yaml。更新前或在别的浏览器里存的，重新粘贴保存一次就能看；看不了时那一行下面写原因和办法。
- 思维链页：「N 项变量读取待核对」是单独一行标题，要核对的条目各自一个框。每个框两行：上面是条目名，右边小胶囊写原因（浅警告色底）；下面小字写变量名。
- 「夜雾」配色恢复层次：正文、次要文字、强调色分开三档，开关、勾选框、主按钮和「已连接」回到灰绿色，卡片底色压暗一点。
- iPhone 上下拉框、搜索框、密钥框改成和其他输入框一样的圆角；搜索框下面不再漏出一截底色。下拉框右边的箭头跟着配色变色。

2.5.0
- 一个站点可以填多个密钥，用于同一个站子的不同分组（例如 Gemini 的按次、按量）：
  - 编辑窗口「密钥」旁点 ＋ 加一行；也可以往密钥框里一次粘贴多行，一行一个，自动拆开。只有一个密钥时和以前一样，就一个框。
  - 两个以上密钥时，每行左边可填分组名，不填就叫「密钥 1」「密钥 2」。按住 ⋮⋮ 拖动调顺序，排在上面的优先。
  - 「获取模型列表」每个密钥各拉一次，行尾显示拉到几个模型。
  - 站点列表里，点多密钥站点右边的「3 组 ▸」展开，每个分组一行，点「切换」直接用这个分组连接。和单密钥站点一样，点其他地方打开编辑窗口。正在用时小字显示当前分组和模型。每个分组记住自己上次用的模型。
  - 选模型时一并选分组，选择框顶上可选「按模型」或「按分组」，默认按模型，选过记在站点上。按模型：每个模型列一次，后面标出哪些分组有它，点模型名用排在上面的分组，点标签换；超过 2 个标签时只显示一个和「+N」，点开全部。按分组：一个分组一段，只展开第一段，搜索时每段都展开。
  - 「当前连接」模型框里，模型名后面跟分组名；选了另一个分组的模型，就换成那个分组的密钥重新连接。
  - 方案记 API 时也记下分组，套用时连回这个分组。
  - 连接或拉取失败时提示「『按次』密钥请求失败（额度用完或已失效）」，不自动换分组。
  - 删到只剩一个密钥时，站点变回普通的单密钥站点。
- 「当前连接」的「测试」（闪电）改成和酒馆的「测试消息」一样：用选中的模型发一句「Hi」。结果写在模型下面一行，如「✓ Successful」「! 503 暂无可用渠道」；认不出的写「未知错误」，点这一行看报错原文。不再先重新套用站点。
- 选模型时可「按分类」，任何站点都能用：
  - 点搜索框旁的「多选」，勾选模型（可「全选搜索结果」），点「新建分类」起名，或「加入…」已有分类。一个模型可以同时在几个分类里。
  - 自建分类排在前面；没分进去的按名字自动归到 Claude、Gemini、GPT、DeepSeek 等系列（标「自动」），认不出的归「其他」。中转站加在模型名前的「[0.07/次][出图gpt3]」这类标签不参与判断。
  - 分类标题右边 ⋯：编辑模型（勾选要留下的）、改名、删除（模型不受影响）。
  - 分类记在站点上，多密钥站点的所有分组共用一套。
- 弹窗重新排过，少弹窗、少往屏幕底部找：
  - 菜单（工具、新建、分组 ⋯、方案 ✏️、已选条目的「更多」、分类 ⋯、来源类型等几个固定选项）贴着刚点的按钮弹出，点外面关掉。
  - 确认、起名这类小窗口放在屏幕中间偏上，键盘弹出也挡不住。
  - 「当前连接」的 ⋯ 在卡片里原地展开类型、密钥、备注和删除、编辑。
  - 方案重命名、模型分类改名就在原处改，回车保存，Esc 取消。
  - 选择模型：列表长时窗口固定高度，只滚列表，搜索框一直在上面；「多选」工具条（已选几个、全选、加入、新建分类）放在搜索框下面，新建分类的名字就在工具条里填。底部的「取消」去掉，用右上角 ✕ 关。
  - 预设、世界书这类带搜索的长列表同样只滚列表。
- 界面细节（按设计规范过了一遍）：
  - 搜索、新建、编辑方案、勾选删除、绑定、选文件这几处的表情符号换成线条图标，和其他图标一致，各家手机上样子也一样。
  - 「方案」页只留一个实心主按钮「保存当前状态为方案」，「＋ 添加站点」改成描边按钮；方案和站点的「切换」用同一种小胶囊。
  - 思维链页顶上的五个数字放进一条，用细线隔开，不再是五个小方块；手机上下面的小字不小于 11px。
  - 不能点的主按钮（如没有问题时的「修复」）改成描边灰字，看得清，也不像能点。
  - 思维链页：结论并进「待核对」那一块，标题就是「N 项变量读取待核对」，下面一行小字写思维链怎么读取，接着是要核对的条目；没有问题时只留一行「没有读取问题 · …」。四个数字（思维链、变量读到、文字提及、未提及）放在这块下面，说明点 ⓘ 展开。
  - 分组菜单加「组内全部开启」「组内全部关闭」（分组标题上的开关只管分组本身）；「上移一位」「下移一位」并成一行。
  - 「清理」各页统计卡片的 ⓘ 放到第一行最右边（如「备份 26 份 · 26.3 MB」那一行）。
  - 编辑站点时密钥框旁有眼睛按钮，点了显示刚填的密钥；已保存的密钥，酒馆开了 allowKeysExposure 才能看到全文，否则提示只能看到开头结尾。
  - 整理页多选的底栏改成「移动、建成分组、删除、更多」；「全部开启」「全部关闭」挪进「更多」。
  - 「本地备份」的自动备份设置默认折起，标题行显示开关和保留几份，点开再调。
  - 选择模型多选时加了「清空」，一下去掉全部勾选（搜索时只去掉搜索结果里的）。
  - 看已保存的密钥：酒馆不让看时，在那一行下面直接写原因和打开方法；只存在本浏览器里的密钥（旧版酒馆）可以直接看。

2.4.1
- 「思维链 → 格式」新增「发现问题时，自动修正这条回复」（按预设开关，默认关闭）：每次生成结束后自动做「修正这条回复」能做的修改，改了弹提示，可在「格式」窗口撤销；下一轮提醒照常按修正前的问题提醒。手动停止、续写的回复不改；末尾只缺结束标签可能是被截断，不自动补，方便继续生成。
- 「修正这条回复」新增一种修法：正文前一大段没被标签包住的思考（爆思维链）原样移进思考区，开头的注释、后面的锚定注释和标题留在原处，不增删文字。

- 上次只搬出了正文、状态栏等还留在思考区末尾的，检查会标出来，修正时照前几条回复放回正文前或正文后。

- 预设、世界书的选择改成小按钮「名称 ▾」，点开是可搜索的列表，预设多的时候好找；手机上省掉「预设」二字。
- 缝合页：来源、目标各一行，「从 [预设 ▾] [名称 ▾] ⋯」「到 [预设 ▾] [名称 ▾]」，不再另放搜索框（点 ▾ 弹出的列表本身可以搜索）；去掉目标上方的提示句，位置提示放进底栏。
- 预设、世界书的选择列表不论多少项都带搜索。
- 整理页工具栏收成一行：预设、🔍 搜索、＋ 新建（条目或分组）、⋯ 工具。
- 说明文字默认收起成一行「ⓘ 说明」：清理各栏、方案、连接选项、背景图。清理各栏顶部只留一行数字摘要。
- 加载体检：顶部一行摘要（启动用时、预设、扩展数据、角色卡），建议只显示一句结论，原因收进「为什么」，「去清理 ›」和它放在同一行；时间线、请求表、排行等都收进「详细数据」。
- 配色改成小色块，只留圆点和名称（说明放在长按 / 悬停提示里）。
- 思维链页五个统计在手机上排成一行。
- 清理页排序改成小字「↕ 大小」，点开选排序方式。
- 复选框不再沿用酒馆的实心方块样式，改成细边框，勾选后填色。
- 扩展数据：「实际检测」「勾选疑似残留」改成小字，和「ⓘ 说明」放在同一行。
- 加载体检：每条建议只显示一句短结论，带数字的完整说明和原因收进「ⓘ 详情」。
- 角色卡：同名组可以「忽略」（或「全部忽略」），这次打开酒馆期间不再提示；点「重新检测」或下次打开酒馆重新检测时会再列出。
- 方案页「保存当前状态为方案」「＋ 添加站点」按钮改小。
- 修正缝合预览在手机上显示不全、平板上左右乱滑：长名称（分组下拉框、条目名）不再把弹窗撑宽。
- 手机基础字号回到 14px，触屏按钮和输入框高度收紧。

数据安全
- 删除世界书、扩展数据、预设前的备份是交给浏览器下载的，浏览器可能拦截或下载失败。现在下载后先停下来，确认文件已经保存再删除；可以重新下载或取消删除。
- 预设正在自动保存时删除或归档它，会先等这次保存结束再删除，删完不会被晚到的保存写回来。
- 关闭面板时先等正在进行的保存结束。「放弃修改」改为「放弃没存上的部分」，并说明已经自动保存的不会撤回。
- 浏览器存储写满、需要清理旧草稿时，只清当前账号的草稿，不动同一浏览器里其他账号的。
- 站点密钥在酒馆密钥库里没了、本浏览器里还有时，重新存进去后记下新编号，之后连接不会每次再存一把。

功能
- 方案卡片的「使用中」要求预设正在用、开关一致、人设和 API 站点也对得上；只有开关一致时标「开关一致」。
- 分组上的「关闭」标记只有柏宝箱运行时才会挡住组内条目。没有柏宝箱时，整组开关和条目是否生效按条目自己的开关显示。
- 世界书比对改称「条目完全相同」，写明比较范围；读取失败的世界书单独列出，不再悄悄跳过。
- 角色卡「内容相同」改为「文字设定相同（头像图片未比较）」，并写明比较了哪些内容。
- 扩展数据「多半是卸载残留」改为「疑似卸载残留，删除前请核对」：没找到使用者不等于可以安全删除。
- 1.8.0 误把「柏宝箱」改成了「百宝箱」，改回「柏宝箱」。

加载体检
- 时间点分开显示：页面 DOM 就绪、酒馆启动完成、启动完成后仍在进行的请求。「聊天可操作」测不到时写「未测得」，不再用启动完成的时间代替。
- 请求按类别统计：全部角色列表和单张角色详情分开，不再当成重复下载；柏宝库、鸡尾酒+ 的快速接口归到对应类别并注明。
- 体积分为实际传输、压缩后、解压后；跨域拿不到的写「未取得」，不再用压缩后的大小冒充实际传输。
- 同类请求同时进行时按时间段并集计算，不相加。
- 去掉「小请求耗时长＝排队」的判断；「实测服务器下载速度」改为「接收速率估计」，并说明不是服务器带宽上限。
- 设置读取不止一次、启动时有设置保存时，只说明记录到的事实，不再指认是哪个扩展。
- 新增「每笔请求明细」（等待首字节、接收阶段）和「导出诊断报告」（脱敏，不上传）。
- 清理页的「打开约快 X 秒」改为「设置下载约少 X（估计）」。

加载与兼容（扩展页设置框）
- 新增「加载与兼容」：显示已在运行的柏宝箱、鸡尾酒、鸡尾酒+、酒馆助手，柏宝库、鸡尾酒+ 的启动桥接，页面由谁的 Service Worker 控制，以及本次设置读取实际走了谁的接口。平时只看页面上已有的信息，不发请求。
- 「检查兼容性」：读取扩展列表、探测柏宝库和鸡尾酒+ 的后端，把「安装」「开启」「后端可用」「运行中」「版本」分开显示；版本标「已识别但未验证」或「未知」。
- 按方面列出由谁负责：设置／预设读取、角色列表、扩展清单与预加载这三项，两个功能都开着时提示重叠，建议只保留一个。本扩展不改其他扩展的开关。
- 本扩展目前没有自己的读取加速，「应用推荐配置」「停用加速」显示为不可用，并写明原因。
- 设置框「检查更新」同时显示当前分支和提交号，装测试分支时可以确认装的是哪一版。

说明
- 本版本没有开发启动读取加速。要先用新的体检比较开关现有加速（柏宝库、鸡尾酒+）前后的实际传输，确认仍有缺口再决定；测量步骤见 docs/implementation-1.9.0.md。
- 以上改动只在模拟页面里测试过，还没有在真实酒馆和真机上验证。

1.8.0
数据安全
- 保存前先核对酒馆里的预设有没有被别处改过（酒馆、百宝箱、其他设备）。改过就暂停自动保存，由你选择：下载两个版本、放弃自己的修改，或覆盖。
- 页面重载后发现未保存的草稿：服务器上的预设没变过才自动接着保存；变过就先问你，不再直接覆盖。
- 自动备份失败时不再照常写入，会让你选择：下载修改前的版本后保存、不备份直接保存，或暂不保存。
- 归档：上传后读回来逐字核对，核对不上或读不到都不删原预设。归档文件名带上预设名。
- 添加站点、获取模型列表时不再换掉酒馆正在用的密钥；密钥保存失败会提示，不再显示成功。取消添加时，刚存进密钥库的密钥一并删掉。
- 删除预设时提示它正被哪些方案、连接配置使用。
- 世界书「内容完全相同」改为比较条目的全部设置（启用、概率、位置、深度等）。
- 删除世界书时，读取失败、没有备份下来的那本不再删除。
- 扩展数据：任何一个文件没读到都算「没查完」；去掉「一键清理」，改为「勾选疑似残留」，逐项确认后再删。
- 缝进世界书前先备份整本世界书；缝完可在底栏撤销刚缝进去的条目。
- 套用方案前，先保存这个预设上没存完的修改，不再直接丢掉。

功能
- 整组开关会同时开关组内条目（酒馆只认条目开关），再开组时只开回原来开着的条目。
- 「去掉重复的一层」只去掉成员完全相同的同名分组，成员只是一部分的分组保留。
- 「全选」只选看得见的条目，不再选中折叠分组里的条目。
- 接入思维链：条目排在思维链之后、或预设没有每轮清空变量的初始化条目时，给出提醒。
- 「修复变量问题」先列出要改的内容，确认后才修改。「变量未被读取」的说法改为「没有找到读取它的开启条目，可能不会发送」。
- 绑定聊天的方案会核对 API 站点；恢复站点时也比较密钥。自动恢复连接失败时不再提示「已恢复」。
- 快速切换世界书时，不会再把旧书的内容显示或缓存到新书名下；重新选择世界书时重新读取。
- 去掉「后台中断补救」：实际使用中几乎不起作用。设置框里的开关一并去掉。
- 思维链识别更准：名称里的英文要整词匹配（Scott、mascot 不再算），正文里顺口提到的 <thinking> 不算。
- 「使用中」站点不再悄悄跟着酒馆里换的模型改；不一致时提示，可点「改记为当前模型」。
- 旧版酒馆（没有密钥库）：站点密钥改为只存在本浏览器，不再明文写进会上传到服务器的设置文件；以前存进去的会自动挪出来。
- 搜索同时匹配名称和正文。
- 整理页的预设列表会随归档、删除、恢复、切换预设刷新。
- 获取模型列表、检查更新、读取扩展列表改用相对路径，酒馆部署在子路径下也能用。
- 加载体检「请求记录满了」的判断修正。
- 大预设的撤销记录少留几份，减少手机上的内存占用。
- 缝合记录不再写入来源预设名，分享预设时不会带出你缝过哪些预设。

新增
- 整理页「工具 → ＋ 新建条目」：放在选中的条目之后，建好直接编辑。
- 多选后「更多 → 复制」：副本放在原条目后面。
- 编辑条目可以改角色、插入位置（按顺序 / 按深度插入聊天记录）、深度。
- 缝合底栏点「已选 N 条」查看全部已选条目，可逐条去掉。
- 斜杠命令只保留 /atelier 和 /焦香鸡翅，去掉 /裁缝铺。

按钮与界面
- 名称统一为「焦香鸡翅」（扩展页设置框里的小铅笔可以改成自己喜欢的名字，留空恢复默认）；改名改为在设置框里直接输入，不再弹浏览器的输入框。

- 「排列方式」从多选菜单挪到「工具」里，改名为「多选排列」；「按标签排序」改名为「按变量名排序」并说明按什么分类。
- 整理页的眼睛图标标为「查看或编辑」。
- 「防止下拉误刷新」说明改为对所有设备生效。
- 备份按钮和备份列表注明「备份只存在这个浏览器里」。
- 顶栏「确认」改名为「完成」（修改本来就已自动保存）。
- 编辑条目改为点「保存」才生效，点「取消」或 ✕ 不改动。
- 缝合底栏「取消」改名为「清空」；移动模式的退出按钮不再是主色。
- 缝合预览每条前的开关加上文字「缝后开启」。
- Esc、返回手势只关最上面的弹窗；弹窗内按 Tab 不会跑到弹窗外；没有弹窗时，Esc 或安卓返回手势关闭面板。

- 手机字号最小 15px，触屏上的按钮、复选框加大；iOS 点进文本框不再放大页面。
- 「已连接 / 未连接」恢复圆点和颜色。
- 「柏宝箱」改为「百宝箱」。
- 版本号接着 1.7.4 往后排（上一版误标为 1.1.0）。

1.7.5（误标为 1.1.0）
- 修复「分组里又套了一层同名分组」：有的预设同时存了百宝箱分组和另一种分组格式（entryGrouping），两个扩展各显示一层。在「整理」中打开这类预设时，顶部会提示，点「去掉重复的一层」即可；之后用本扩展保存时也会自动去掉重复的一层。
