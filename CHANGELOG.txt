焦香鸡翅 1.9.0

整理分组、跨预设缝合、思维链检查、方案、加载体检、预设清理。
打开方式：魔棒菜单 →「焦香鸡翅」，或在输入框发送 /atelier（也可用 /焦香鸡翅）。名称可在扩展页设置框中修改。
修改即时自动保存，每批修改开始前自动备份。扩展版和脚本版同时安装时，只有扩展版启动。

1.9.0
数据安全
- 删除世界书、扩展数据、预设前的备份是交给浏览器下载的，浏览器可能拦截或下载失败。现在下载后先停下来，确认文件已经保存再删除；可以重新下载或取消删除。
- 预设正在自动保存时删除或归档它，会先等这次保存结束再删除，删完不会被晚到的保存写回来。
- 关闭面板时先等正在进行的保存结束。「放弃修改」改为「放弃没存上的部分」，并说明已经自动保存的不会撤回。
- 浏览器存储写满、需要清理旧草稿时，只清当前账号的草稿，不动同一浏览器里其他账号的。
- 站点密钥在酒馆密钥库里没了、本浏览器里还有时，重新存进去后记下新编号，之后连接不会每次再存一把。

功能
- 方案卡片的「使用中」要求预设正在用、开关一致、人设和 API 站点也对得上；只有开关一致时标「开关一致」。
- 分组上的「关闭」标记只有柏宝箱运行时才会挡住组内条目。没有柏宝箱时，整组开关和条目是否生效按条目自己的开关显示。
- 世界书比对改称「条目完全相同」，写明比较范围；读取失败的世界书单独列出，不再悄悄跳过。
- 角色卡「内容相同」改为「文字设定相同（头像图片未比较）」，并写明比较了哪些内容。
- 扩展数据「多半是卸载残留」改为「疑似卸载残留，删除前请核对」：没找到使用者不等于可以安全删除。
- 1.8.0 误把「柏宝箱」改成了「百宝箱」，改回「柏宝箱」。

加载体检
- 时间点分开显示：页面 DOM 就绪、酒馆启动完成、启动完成后仍在进行的请求。「聊天可操作」测不到时写「未测得」，不再用启动完成的时间代替。
- 请求按类别统计：全部角色列表和单张角色详情分开，不再当成重复下载；柏宝库、鸡尾酒+ 的快速接口归到对应类别并注明。
- 体积分为实际传输、压缩后、解压后；跨域拿不到的写「未取得」，不再用压缩后的大小冒充实际传输。
- 同类请求同时进行时按时间段并集计算，不相加。
- 去掉「小请求耗时长＝排队」的判断；「实测服务器下载速度」改为「接收速率估计」，并说明不是服务器带宽上限。
- 设置读取不止一次、启动时有设置保存时，只说明记录到的事实，不再指认是哪个扩展。
- 新增「每笔请求明细」（等待首字节、接收阶段）和「导出诊断报告」（脱敏，不上传）。
- 清理页的「打开约快 X 秒」改为「设置下载约少 X（估计）」。

加载与兼容（扩展页设置框）
- 新增「加载与兼容」：显示已在运行的柏宝箱、鸡尾酒、鸡尾酒+、酒馆助手，柏宝库、鸡尾酒+ 的启动桥接，页面由谁的 Service Worker 控制，以及本次设置读取实际走了谁的接口。平时只看页面上已有的信息，不发请求。
- 「检查兼容性」：读取扩展列表、探测柏宝库和鸡尾酒+ 的后端，把「安装」「开启」「后端可用」「运行中」「版本」分开显示；版本标「已识别但未验证」或「未知」。
- 按方面列出由谁负责：设置／预设读取、角色列表、扩展清单与预加载这三项，两个功能都开着时提示重叠，建议只保留一个。本扩展不改其他扩展的开关。
- 本扩展目前没有自己的读取加速，「应用推荐配置」「停用加速」显示为不可用，并写明原因。
- 设置框「检查更新」同时显示当前分支和提交号，装测试分支时可以确认装的是哪一版。

说明
- 本版本没有开发启动读取加速。要先用新的体检比较开关现有加速（柏宝库、鸡尾酒+）前后的实际传输，确认仍有缺口再决定；测量步骤见 docs/implementation-1.9.0.md。
- 以上改动只在模拟页面里测试过，还没有在真实酒馆和真机上验证。

1.8.0
数据安全
- 保存前先核对酒馆里的预设有没有被别处改过（酒馆、百宝箱、其他设备）。改过就暂停自动保存，由你选择：下载两个版本、放弃自己的修改，或覆盖。
- 页面重载后发现未保存的草稿：服务器上的预设没变过才自动接着保存；变过就先问你，不再直接覆盖。
- 自动备份失败时不再照常写入，会让你选择：下载修改前的版本后保存、不备份直接保存，或暂不保存。
- 归档：上传后读回来逐字核对，核对不上或读不到都不删原预设。归档文件名带上预设名。
- 添加站点、获取模型列表时不再换掉酒馆正在用的密钥；密钥保存失败会提示，不再显示成功。取消添加时，刚存进密钥库的密钥一并删掉。
- 删除预设时提示它正被哪些方案、连接配置使用。
- 世界书「内容完全相同」改为比较条目的全部设置（启用、概率、位置、深度等）。
- 删除世界书时，读取失败、没有备份下来的那本不再删除。
- 扩展数据：任何一个文件没读到都算「没查完」；去掉「一键清理」，改为「勾选疑似残留」，逐项确认后再删。
- 缝进世界书前先备份整本世界书；缝完可在底栏撤销刚缝进去的条目。
- 套用方案前，先保存这个预设上没存完的修改，不再直接丢掉。

功能
- 整组开关会同时开关组内条目（酒馆只认条目开关），再开组时只开回原来开着的条目。
- 「去掉重复的一层」只去掉成员完全相同的同名分组，成员只是一部分的分组保留。
- 「全选」只选看得见的条目，不再选中折叠分组里的条目。
- 接入思维链：条目排在思维链之后、或预设没有每轮清空变量的初始化条目时，给出提醒。
- 「修复变量问题」先列出要改的内容，确认后才修改。「变量未被读取」的说法改为「没有找到读取它的开启条目，可能不会发送」。
- 绑定聊天的方案会核对 API 站点；恢复站点时也比较密钥。自动恢复连接失败时不再提示「已恢复」。
- 快速切换世界书时，不会再把旧书的内容显示或缓存到新书名下；重新选择世界书时重新读取。
- 去掉「后台中断补救」：实际使用中几乎不起作用。设置框里的开关一并去掉。
- 思维链识别更准：名称里的英文要整词匹配（Scott、mascot 不再算），正文里顺口提到的 <thinking> 不算。
- 「使用中」站点不再悄悄跟着酒馆里换的模型改；不一致时提示，可点「改记为当前模型」。
- 旧版酒馆（没有密钥库）：站点密钥改为只存在本浏览器，不再明文写进会上传到服务器的设置文件；以前存进去的会自动挪出来。
- 搜索同时匹配名称和正文。
- 整理页的预设列表会随归档、删除、恢复、切换预设刷新。
- 获取模型列表、检查更新、读取扩展列表改用相对路径，酒馆部署在子路径下也能用。
- 加载体检「请求记录满了」的判断修正。
- 大预设的撤销记录少留几份，减少手机上的内存占用。
- 缝合记录不再写入来源预设名，分享预设时不会带出你缝过哪些预设。

新增
- 整理页「工具 → ＋ 新建条目」：放在选中的条目之后，建好直接编辑。
- 多选后「更多 → 复制」：副本放在原条目后面。
- 编辑条目可以改角色、插入位置（按顺序 / 按深度插入聊天记录）、深度。
- 缝合底栏点「已选 N 条」查看全部已选条目，可逐条去掉。
- 斜杠命令只保留 /atelier 和 /焦香鸡翅，去掉 /裁缝铺。

按钮与界面
- 名称统一为「焦香鸡翅」（扩展页设置框里的小铅笔可以改成自己喜欢的名字，留空恢复默认）；改名改为在设置框里直接输入，不再弹浏览器的输入框。
- 缝合页：「新建分组」挪到目标列表顶上，「搬到新版」挪到来源旁的「⋯」里；预览里的两个选项和两边写法分析收进「更多选项」；「单选」「setvar / addvar」等说法改为「多选一」「可叠加」。
- 「排列方式」从多选菜单挪到「工具」里，改名为「多选排列」；「按标签排序」改名为「按变量名排序」并说明按什么分类。
- 整理页的眼睛图标标为「查看或编辑」。
- 「防止下拉误刷新」说明改为对所有设备生效。
- 备份按钮和备份列表注明「备份只存在这个浏览器里」。
- 顶栏「确认」改名为「完成」（修改本来就已自动保存）。
- 编辑条目改为点「保存」才生效，点「取消」或 ✕ 不改动。
- 缝合底栏「取消」改名为「清空」；移动模式的退出按钮不再是主色。
- 缝合预览每条前的开关加上文字「缝后开启」。
- Esc、返回手势只关最上面的弹窗；弹窗内按 Tab 不会跑到弹窗外；没有弹窗时，Esc 或安卓返回手势关闭面板。
- 条目行、分组头可以用键盘选中和操作；魔棒菜单项支持回车。
- 手机字号最小 15px，触屏上的按钮、复选框加大；iOS 点进文本框不再放大页面。
- 「已连接 / 未连接」恢复圆点和颜色。
- 「柏宝箱」改为「百宝箱」。
- 版本号接着 1.7.4 往后排（上一版误标为 1.1.0）。

开发

1.7.5（误标为 1.1.0）
- 修复「分组里又套了一层同名分组」：有的预设同时存了百宝箱分组和另一种分组格式（entryGrouping），两个扩展各显示一层。在「整理」中打开这类预设时，顶部会提示，点「去掉重复的一层」即可；之后用本扩展保存时也会自动去掉重复的一层。
