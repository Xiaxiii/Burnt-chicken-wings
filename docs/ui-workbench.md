# 3.1.0 横向工作台

本次以 `claude/ui-redesign` 的 `12a5abeb`（3.0.3）为功能基底。四个指定分支已核对：多密钥分支是 2.7.2 的祖先，2.7.2 和 ui-rebuild 都已包含在最新 ui-redesign 中。没有把本地旧版 2.6.8 当成功能基底。

## 设计决定

使用仓库的 `design-taste-frontend` 和 `frontend-design` skill。app draw 选择 Framed sheet，最终种子 `502657853`，保留中文字体方案（`--keep type`）。使用本地可用的 Noto Sans CJK SC，按平台回退至苹方、微软雅黑，不增加字体网络请求。

新配色「青序」：框架 `#eff4f0`，纸面 `#ffffff`，正文 `#243b31`，次级文字 `#606e66`，状态与选中数据 `#1b6c80`，细分隔线 `#e0e8e2`。主操作使用正文墨色。已选主题继续生效；原有绘画、毛玻璃、自定义背景是保留功能，新默认工作台不使用这些效果。

横向任务导航腾出双栏缝合的宽度。预设页的左栏用于当前预设的真实分组，而不是再次列出页面导航。目录显示开启数与总数，点击会展开并定位对应分组。工作纸、目录、条目与保存状态均使用当前 Draft，未添加静态示意数据。

| 页面 | 首先回答的问题 | 结构变化 |
| --- | --- | --- |
| 预设 | 当前预设有哪些分组和已开启条目？ | 分组目录、真实统计、工作纸列表、独立编辑详情 |
| 缝合 | 已选哪些材料，放在哪里？ | 实际状态驱动的三步流程、来源与目标工作区、材料托盘 |
| 回复 | 这条回复哪里不符合规则？ | 检查与结果为主列，格式规则及自动处理为设置列；手机可直达规则 |
| 连接 | 当前用哪个站点和模型，如何切换？ | 站点资源与当前连接并排，方案和跟随选项有独立视图 |

## 功能边界

核心解析、预设操作、宿主保存、缝合适配、回复修复、多密钥与余额逻辑沿用 3.0.3。保留旧入口 `organize`、`cot`、`suture`、`more/api` 和 `more/schemes`。

全局自动保存、撤销、确认、冲突处理、备份及返回手势继续存在。辅助页面清理、备份、体检、外观均保留。主题引擎增加新默认配色，继续校正对比度、防护宿主样式并跟随系统。

预设目录在已有读取索引中统计；单行开关只更新对应行与目录统计。保存状态通知不重绘列表。手机编辑详情独占可见区域，安全区沿用视口同步结果。

## 验证

- 核心逻辑、浏览器功能回归及 1200 → 1200 条目性能检查。
- 1440、768、390 三宽度检查目录、选择、搜索、焦点、连接视图和缝合流程。
- design-taste app inspector 在默认工作台的三个宽度中无 FAIL 或 WARN。
- 模拟酒馆使用代码生成的预设；没有使用或分发真实预设与密钥。
- 本地未连接真实付费 API。连通性、余额、宿主保存等沿用现有模拟协议测试，实际部署仍由 SillyTavern 的接口和权限决定。
