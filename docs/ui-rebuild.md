## 一、功能清单（2.6.20）

### 1. 外壳与全局（app.js、state.js、dom.js）

- 面板：全屏覆盖层 `#pa-root`；按实际可见高度定高（`--pa-vh`），处理安全区重复留白、外层 transform 造成的顶部偏移（syncViewport）。
- 顶栏：标识、名称（可改名）、「by EC」；保存状态（已自动保存 / 保存中… / 保存失败：… / 已暂停保存：预设在别处被改过 / 已暂停保存：备份失败）；「撤销」（撤上一步，toast「已撤销：标签」）；「完成」（结束本批修改，清空撤销记录）；「重试保存」/「处理」（被挡住时打开处理对话框）；「备份」（当前焦点预设的本地备份列表）；关闭。
- 页签：整理 / 缝合 / 思维链 / 更多。
- 键盘：条目行、分组头上 Enter/Space 等于点击；Esc 关面板（有弹窗时由弹窗处理，原地改名输入框除外）。
- 返回手势：打开面板时 pushState；返回先关最上层弹窗，再关面板。
- 关闭流程：等待进行中的保存；被挡住的先处理；仍有未存修改时问「暂不处理（下次打开仍在）/ 放弃没存上的部分 / 全部保存」。
- open(tab, sub)：丢弃干净草稿、焦点预设设为当前预设、应用主题、隐藏悬浮球、显示页签、flushAsks。
- 外部接口：`window.__presetAtelier = { version, kind, open, destroy }`；`open("more","schemes"|"look"|"health")`、`open("organize"|"suture"|"cot")` 被测试和扩展页使用。
- 魔棒菜单项（保持在菜单最后）；入口模式：魔棒菜单 / 悬浮球 / 两个都要 / 都不要（`settings.entry`，兼容旧 `floatBall`）。
- 悬浮球：点开、拖动（transform）、松手贴左右边、位置按比例存（`floatBallPos`）、面板打开时隐藏。
- 斜杠命令 `/atelier`、`/焦香鸡翅`。
- 防下拉误刷新（`noPullRefresh`，默认开）。
- 扩展页设置框：名称（就地改名，留空恢复默认）、版本（扩展版/脚本版）、检查更新 → 更新 → 刷新页面、防下拉误刷新开关与说明、入口选择与「都不要」说明、「加载与兼容」卡片（快速状态、检查兼容性表格、加速领域重叠提示）、最近两版更新说明、页脚打开方式与 GitHub 链接、「打开」「加载体检」按钮。
- 换角色/聊天：同一聊天只处理一次；按聊天绑定自动套用方案（预设已归档则先恢复）；900ms 后弹「预设 / 模型 / 方案」提示（`chatToast`，仅聊天补全）。
- 监视他人写回旧重复分组（mirrorWrites）。
- 迁移 apiRule（关闭酒馆预设绑定连接，一次）。
- 事件：PRESET_CHANGED（推理格式跟随、notePresetUse、丢弃干净草稿、重画面板；正则刷新时跳过）、CHAT_CHANGED、回复检查、变量监视、语义审查。
- 备份对话框：列出焦点预设的本地备份（时间、原因）→ 恢复（可撤销）/ 下载 JSON；无备份或自动备份关闭时提示。
- 草稿：自动保存（350ms）、本地草稿恢复、冲突对话框（下载两个版本 / 放弃我的修改 / 用我的修改覆盖）、备份失败对话框（暂不保存 / 不备份直接保存 / 下载修改前的版本后保存）、草稿恢复对话框（下载草稿 / 丢弃草稿 / 用草稿覆盖）。
- 展开收起记忆：`settings.fold[area][key]`。
- 通用原语：toast、弹层（底部升起 / 居中卡片 / 贴按钮菜单）、原地改名、确认、删除前提供备份下载、输入框、选项菜单（含一行两个的成对选项）、复制文字（http 回退）、搜索输入（输入法感知、延迟筛选）、ⓘ 说明折叠。

## 二、新设计

### 1. 结构

- 宽屏（≥ 960px）：左侧导航栏 220px ＋ 主区。导航栏自上而下：标识与名称、当前预设（全局，点开换预设，标「使用中」）、预设 / 缝合 / 回复 / 连接、分隔线、清理 / 备份 / 体检 / 外观。主区顶部是页头：页名、页内视图切换、保存状态（已保存 / 保存中 / 保存失败 · 重试 / 已暂停 · 处理；有修改时「撤销」「完成」）、关闭。
- 窄屏（< 960px）：顶栏（标识、当前预设、保存状态、关闭）＋ 底部五个页签：预设 / 缝合 / 回复 / 连接 / 更多。「更多」列出清理、备份、体检、外观。
- 当前预设全局唯一：预设页、缝合页的目标、回复页的规则都按它；缝合页「到」一侧即当前预设。
- 编辑条目：宽屏在主区右侧打开详情栏（列表与正文并排），窄屏整屏推入。

### 2. 各页

- 预设：视图 条目 / 思维链 / 变量。
  - 条目：工具行（搜索框、＋新建、⋯工具）、横幅（重复分组、分散分区）、条目列表；选中后底部操作栏；移动、新建分组时列表上方出现选位置提示条。
  - 思维链：统计四格兼作筛选（思维链 / 变量读到 / 文字提及 / 未提及）、结论行、多套思维链警告、思维链条目（读取的变量、不是思维链、手动指定）、条目关联列表（按分组，未提及的「接入」）、已预留变量；有变量问题时一行链接到变量视图。
  - 变量：待核对的变量读取（原「思维链」页的卡片）、批量修复、顺序风险、未推演条目、操作顺序、当前状态快照、生成前后变化记录。
- 缝合：宽屏左右两栏；窄屏「从 / 到」两栏切换，底栏常驻（已选、位置、预览）。来源类型、目标类型用分段控件。预览为大窗口，逐条可展开。正则缝合、搬到新版在页头操作中。
- 回复：整页。状态栏卡；格式规则（正文标签、必需标签、思考标签，改动即校验即保存）；生成后开关（提示、自动修正、状态栏自动改回、状态栏提醒、AI 自动审查）；检查（最近回复 / 粘贴文字）与结果；AI 语义审查。生成后的提示点进来时跳到本页并检查最近回复。
- 连接：当前连接卡、方案、站点、选项。站点编辑、模型选择、推理格式编辑为窗口。
- 清理：下划线页签 预设 / 扩展数据 / 角色卡 / 世界书；勾选后底部操作栏。
- 备份：自动备份设置、按预设（含世界书）列出全部本地备份，可逐份恢复、下载、删除；精简、删除全部。原顶栏备份按钮并入此页。
- 体检、外观：整页。

### 3. 设计系统
