# 大预设性能、主题对比度与缝后总开关

本次修改用于 main 2.0.3 和 Claude 审阅分支 2.2.4；两个分支各自保留原有功能，不互相合并。

## 性能修复与证据

- 列表原来每行重新核对整个思维链区段，每次核对又在线性查找提示词。现在每个同步只读操作建立一次索引，每批准备一次区段；作用域结束即清理，后续直接修改正文、顺序、开关和分组仍会重新读取。
- 折叠组保留标题、成员计数、选择和插入位置信息，展开或搜索命中时才生成内部行。
- 保存状态通知只更新保存栏；列表和思维链分析只在相关内容或焦点变化且页面可见时刷新。隐藏的「更多 → 方案」也不会跟着刷新。
- 缝合规划复用同步批次中的分析；初次预览共享目标画像，单条和批量改选重新分析，不跨异步操作保存旧分析结果。

1200 条公开合成预设的回归结果：

| 检查 | 原 main `c7521e3` | 修复后 |
| --- | ---: | ---: |
| 展开列表时的完整区段核对调用 | 1200 | 1 |
| 折叠列表中的条目 DOM 行 | 1200 | 0 |
| 展开列表时线性查找提示词实际扫描的元素数 | 869,041,200 | 0（使用批次索引） |

手机和桌面浏览器同时验证 1200 条来源 → 1200 条目标：一次单项修改并自动保存只绘制列表一次；单独的保存状态通知不重画；四条缝合预览只分析来源和目标各一次。基准统计的耗时包含测试插桩，不能当作用户设备上的实际点击耗时。

## 主题与控件

按实际底色以及卡片、选择状态、输入框的叠加表面纠正文字与强调色。勾选图案和按钮文字按强调色选择深浅色；本地控件样式防止宿主把复选框、下拉框或输入框改成白底白字。仅监听 html/body 的 class/style 与系统明暗变化，合并处理且隐藏时暂停，不扫描全页 DOM。去掉近不透明面板上冗余的背景模糊。

主题测试覆盖手机、桌面各四种宿主配色（正常明暗、浅底浅字、深底深字）、真实表面 RGBA 与祖先透明度、宿主 `!important` 输入框样式、内置 night/goose、动态换主题以及部分开启的居中滑块。用户自选照片且遮罩很低时，图片每个像素的对比度不在这些断言范围内。

## 缝后总开关与数据安全

预设和世界书预览都有一个左右拨动的总开关：右边全部开启，左边全部关闭。逐条调整后如有开有关，则显示部分开启和居中滑块；空格键也能操作。只更新本次材料的预览选择，不重新分析或重建条目，确认缝合后才写入。

实际确认全关、全开、仅一条开启三种方案，并逐次撤销：已有条目开关、分组标记、正文、其他角色顺序和来源预设保持原值。世界书全关正确写入 `disable=true`，保留原条目并可撤销。取消预览不保存。
